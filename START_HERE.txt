MULASTREAM VENTUREOS ENHANCED — LOCAL PROTOTYPE

1. Extract to a NEW folder. Do not overwrite your current installation.
2. Open that folder in VS Code / PowerShell.
3. Run: python -m pip install -r requirements.txt
4. Ensure Ollama is running and qwen3:4b appears under: ollama list
5. Run: $env:OLLAMA_MODEL="qwen3:4b"
6. Run: python -m uvicorn app:app --host 127.0.0.1 --port 8501
7. Visit: http://127.0.0.1:8501

The distributed archive deliberately has NO database, accounts or personal chats.
To reuse your accounts, stop both servers, back up the original data/ventureos.sqlite3, and copy it into this project's data folder.
